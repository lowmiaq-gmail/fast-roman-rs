# fast-roman-rs 指南 (Agent Guide)

## 1. 本层级核心职责

将冻结的 `zopefoundation/roman==5.2` 完整替代为 Rust-backed Python distribution，保留 `roman` namespace、公开 API、exception、regex、CLI、typing 和 Python/PyPy fallback contract。

## 2. 计划目录

- `/src`: Rust conversion and validation core.
- `/python/roman`: minimal compatibility wrapper, CLI, typing marker, and public namespace.
- `/fallback`: canonical pure-Python fallback artifact inputs.
- `/tests`: candidate, differential, CLI, packaging, and artifact-inspector gates.
- `/upstream`: frozen oracle and unmodified upstream test inputs.
- `/scripts`: isolated oracle/candidate, artifact, benchmark, and release verification tools.
- `/.github/workflows`: packaged-wheel CI and immutable release workflow.
- `/benchmarks`: raw semantic-equality-first benchmark evidence.

## 3. 运行、测试与输出规范

- 冻结 contract 在 `UPSTREAM-CONTRACT.md` 和 `COMPATIBILITY.md`；实现不得改写 upstream tests。
- 发布前必须通过 Rust gates、candidate tests、完整 upstream suite、至少 10,000 例隔离差分、fresh wheel/sdist、artifact inspection 和公网 PyPI reinstall。
- native wheel 使用 PyO3 abi3；非 CPython/不匹配平台使用同版本 universal fallback。
- 重 benchmark 输出放入 `/private/tmp` 或明确的 `benchmarks/` 证据文件，不把 build cache 提交到仓库。

## 4. 阶段性清理清单
